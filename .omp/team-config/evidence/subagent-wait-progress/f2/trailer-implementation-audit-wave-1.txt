## 1. Goal and behavioural contract

Blocker B1: **High** — `packages/coding-agent/src/async/job-control.ts:185-194,219-222`. In an ordinary multi-agent spawn, each job’s progress array contains the whole batch. If a job ID collides with an existing job, the manager suffixes that job ID while its `agentId` remains unchanged (`task/index.ts:1129-1145,1199-1207,1585-1590`; `async/job-manager.ts:895-913`). The selector matches the suffixed job ID rather than the agent ID and falls back to the first batch record. The newly displayed requests, cost and context can therefore belong to another agent, causing the parent to misidentify which agent is looping. This violates the latest-progress invariant; the misleading display is reversible. Fix by selecting the record for the job’s actual agent identity, and add a multi-agent collision regression covering wait and proc output. **class:** progress-record identity mismatch. **sites:** the repository search `candidate\.id ===|progressRecord|\.progress\.find\(` over coding-agent and TUI source found the relevant selector only at `job-control.ts:185-194`; all four new numeric fields consume that selected record at `:219-222`. The class is **not closed** at that site. The selector pre-existed, but this change exposes its incorrect selection through the new model-facing progress fields.

## 2. Correctness, regressions, architecture, wire contracts

**Non-blocking note:** `job-control.ts:278` renders a positive cost below half a cent as `$0.00`, and `:286` renders a valid zero completion estimate as `~0%`. Both conflict with the brief’s “no 0-valued parts” constraint; the plan separately specifies displaying completion whenever present. The small-cost display is misleading but does not, by itself, defeat the loop-identification goal or a stated merge-gate criterion. Consider a nonzero representation such as `<$0.01` and resolve the zero-percent wording.

The suffix is centralized and guarded by task type and running status. Snapshot fields are optional, and the proc listing avoids duplicating duration.
