## Final report

The chat field of the desktop app now holds exactly `qa f1 agent check`.

**How it was done** (shared driver, Spectre 0.9.0):
- **Preflight:** against the default port 8080, the backend check failed with HTTP 404, so something other than the backend answers there. With `--port 8081` all four checks passed and the backend health was `UP`.
- **Attach:** the driver attached to the app's one running process (pid 24595). Before typing, `chat-input` was a single node, enabled, and empty (`textLength=0`).
- **Type:** `desktop type chat-input "qa f1 agent check"` wrote 17 characters.

**Proof:** `desktop find chat-input --equals "qa f1 agent check"` read the field back as `count=1 enabled=true focused=true textLength=17 equals=true`. That is an exact text match against the field itself.

- No sign-in was needed, no screenshot or UI tree was taken, and no evidence files were written.
- The text was not sent; it is still in the field.
- I detached the driver session afterwards.
