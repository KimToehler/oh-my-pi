## Final report

Account 2 is signed in on the iOS simulator, and the app opened on the onboarding welcome screen (`onboarding-welcome`). Account 2 is the onboarding account, so that is the expected place to land.

**Screen after sign-in** (shown above): "Willkommen bei Onara", "Schön, dass du da bist.", the Onara wordmark, the language chips with Deutsch selected and English beside it, "Etwa zwei Minuten." and the **Loslegen →** button. It's saved at `/tmp/onara-signin-acct2-out/after-signin.png`.

- **Backend:** the first readiness check failed because Docker holds port 8080 and returns HTTP 404 there. The real backend is on 8081, which is also the port the installed debug app was built for, and the check passed there.
- **How it signed in:** it ran in one Maestro run, which first relaunched the app with its local data cleared and then ran the repository's iOS sign-in flow. No login-page screenshot or screen dump was taken, and the screenshot was taken only after sign-in had finished. The run passed in 42 s.
- **Credential safety:** the run deleted its `commands.json` and blanked the credentials in its three logs. The screenshot folder scanned clean.
- **One scan hit:** the scan flagged my temporary flow file in `/tmp/onara-signin-acct2-flow/`. The file held no credential, only the path `~/...`. The match means one configured account value is the string `[redacted]`. I deleted the folder anyway.
