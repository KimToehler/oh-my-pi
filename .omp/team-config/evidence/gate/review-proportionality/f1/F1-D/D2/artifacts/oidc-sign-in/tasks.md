# Tasks

Test classes live in `shared/src/commonTest/kotlin/` unless a task names another source set. `commonTest` runs on the Android host JVM (`testDebugUnitTest`) and on the iOS simulator (`iosSimulatorArm64Test`). Prerequisites: JDK 17+, Android SDK (compileSdk 36), Xcode with an iOS simulator, Docker (task 7.1), and a booted Android emulator (task 5.1).

## 6. Credential confidentiality

- [ ] 6.1 Add `app.auth.SecretLeakTest` (commonTest). It drives the paths of tasks 3.1, 3.2 and 4.1 with sentinel tokens `SENTINEL-ACCESS-7f3a`, `SENTINEL-REFRESH-7f3a`, `SENTINEL-ID-7f3a`, and an ID-token `email` claim `SENTINEL-EMAIL-7f3a`. The paths are: sign-in success, each validation failure, PKCE `invalid_grant`, refresh success, rejection, temporary failure, store read/write/delete failure and untrusted origin. It collects every thrown exception's `message`, `toString()` and full cause chain, plus every emitted `SessionState`, and asserts that none contains `SENTINEL-`. Add `app.auth.StdStreamLeakTest` (`androidUnitTest`): the same paths with `System.out` and `System.err` redirected to buffers, asserting no `SENTINEL-`. Verify: `./gradlew :shared:testDebugUnitTest --tests 'app.auth.SecretLeakTest' --tests 'app.auth.StdStreamLeakTest' :shared:iosSimulatorArm64Test --tests 'app.auth.SecretLeakTest'`

## 7. Keycloak integration

- [ ] 7.1 Add a disposable local Keycloak test stack; its synthetic credentials grant nothing outside it. `shared/testing/keycloak/realm-oidc-it.json`: realm `oidc-it`; public client `mobile-app` with standard flow only, `pkce.code.challenge.method` `S256` and redirect URI `app.oidc.it:/callback`; user `it-user` with a synthetic password. `shared/testing/keycloak/run-it.sh`: generates a throwaway self-signed certificate for `127.0.0.1`; starts `quay.io/keycloak/keycloak:26.4.0` with `start-dev --import-realm`, HTTPS on `127.0.0.1:8443` and that certificate; waits for the realm's discovery document; runs `./gradlew :shared:testDebugUnitTest -PoidcIt --tests 'app.auth.KeycloakIntegrationTest'` with `OIDC_IT_BASE_URL` and `OIDC_IT_CA`; removes the container on exit. `app.auth.KeycloakIntegrationTest` (`androidUnitTest`, OkHttp engine trusting only `OIDC_IT_CA`) fails, not skips, when either variable is missing. Its `TestCodeAuthFlow` performs the browser step over HTTP: it fetches the authorization URL, posts the login form and captures the redirect without following it. It never prints a token. Tests: `firstSignIn` (`SignedIn`, and `GET /realms/oidc-it/protocol/openid-connect/userinfo` through `apiHttpClient` with API origin `https://127.0.0.1:8443` returns 200); `wrongPkceVerifier` (the stored request's verifier is replaced before redemption; Keycloak answers `invalid_grant`, the state is `SignedOut` and the store is empty); `refreshBeforeNextRequest` (fake clock +241 s; the next userinfo request carries a different access token and returns 200); `rejectedRefreshSignsOut` (the admin API logs the user out, then fake clock +241 s; the request fails with `SignedOutByServer`, the store is empty and the userinfo endpoint receives no request). Verify: `shared/testing/keycloak/run-it.sh`
