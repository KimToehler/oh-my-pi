+# Spec Delta
+
+## Purpose
+Report how much of a quota is left, so callers never display a negative allowance.
+
+## ADDED Requirements
+
+### Requirement: Remaining quota is never negative
+`remaining(used, limit)` SHALL return `limit - used` while usage is within the limit and `0` once it is not.
+
+#### Scenario: Usage within the limit
+- **WHEN** `remaining(3, 10)` is called
+- **THEN** it returns `7`
+
+#### Scenario: Negative control
+- **WHEN** `remaining(12, 10)` is called with usage above the limit
+- **THEN** a negative result `-2` MUST fail the check; the correct result is `0`
+
+### Requirement: Remaining quota rejects fractional values
+`remaining(used, limit)` SHALL throw a `RangeError` when `used` or `limit` is not an integer.
+
+#### Scenario: Integer values are accepted
+- **WHEN** `remaining(0, 5)` is called
+- **THEN** it returns `5`
+
+#### Scenario: Negative control
+- **WHEN** `remaining(2.5, 10)` is called with a fractional usage
+- **THEN** returning `7.5` MUST fail the check; the correct outcome is a thrown `RangeError`

+/** Remaining allowance, never negative; both values must be integers. */
+export function remaining(used: number, limit: number): number {
+	if (!Number.isInteger(used) || !Number.isInteger(limit)) throw new RangeError("quota values must be integers")
+	return Math.max(0, limit - used)
