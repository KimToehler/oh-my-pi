## Limitations

- Rows 3–5 use `--install published` (npm `@oh-my-pi/pi-coding-agent@18.11.1`). `--install source` and the evo evaluate path (which defaults to source mode) need `packages/natives/native/pi_natives.linux-arm64.node`. That file is absent locally and no Rust toolchain is installed, so evaluate-launched trials exit with `Failed to load pi_natives native addon for linux-arm64` (`NonZeroAgentExitCodeError`, `started=false`). This is a pre-existing environment requirement documented in the package README. The coding-agent async task-usage change is proven by `sdk-task-async-guidance.test.ts` (row 1), not by a live trial.
- The first source-mode attempt surfaced R9 (`oven/bun:>=1.4` → `docker: invalid reference format`). R9 is fixed and covered by `runner.test.ts` `resolveBunImageVersion`; the retry built the Linux deps tree with `oven/bun:1.4.2`.
