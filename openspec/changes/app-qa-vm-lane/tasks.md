# Tasks

Paths are relative to the repository root, and `S` is `team-config/agent/skills/app-qa-drivers/scripts`. Apply starts after this branch has been rebased onto `main` with `feat/app-qa-computer-use-exception` merged (design D11).

Every driver task is test-first: its new tests are run and seen failing before the code they cover is written. The tests use the existing harness with fake tools on the test PATH and a private HOME (`S/qa.test.mjs:1-5`), plus these fakes:

- `lume`: logs its argument vectors and keeps a clone list in a state file.
- `ssh`: logs its argument vector, runs the joined remote command through `sh -c` (as sshd does) in a guest directory on the local disk, and can be told to exit 255.
- `launchctl`, `java`: test doubles for the desktop start.

Test names start with their area (`config:`, `lane:`, `lease:`, `stage:`, `target:`, `route:`), so each Verify selects its own.

## 2. Leases and slots

- [ ] 2.1 Table lock, slots and lease record (spec "Leases take one of a fixed number of host-wide slots, one lease per worktree", design D4): `${TMPDIR}/app-qa/vm/table.lock` uses `mkdir` plus a pid, and a stale lock (dead pid) is taken over. It is held only for table reads and mutations. Under the lock, `vm up` finds this worktree's slot or creates a free `slot-N` and writes `lease.json` at once, with the worktree's real path, the clone name, the owner pid, `state: starting`, the targets and `lastUsed`. A second `vm up` while the lease is `starting` with a live owner exits 2 naming that pid. When every slot is held, `vm up` exits 2 naming each holder's worktree and last use. Tests: two worktrees started together, with the fake `lume clone` held open, each get their own slot and neither clone is deleted; two `vm up` started together in one worktree give one slot and one exit 2 naming the owner; a third worktree is refused with no `lume clone` in the fake log; two worktrees started together for one free slot give exactly one clone. Verify: `node --test --test-name-pattern='^lease: (parallel|same-worktree|refuse|simultaneous)' team-config/agent/skills/app-qa-drivers/scripts/qa.test.mjs`
- [ ] 2.2 Reclaim, sweep and busy markers (spec "Idle and orphaned VMs are reclaimed, busy and starting ones never", design D4): routed commands register and remove `busy/PID` under the lock and set `lastUsed` at both ends. `vm up` refresh and `vm down` exit 2 naming a live busy pid. With no free slot, `vm up` reclaims the `ready` lease idle longest beyond `idleMinutes` that has no live busy pid: it marks the lease `closing` under the lock, runs `lume stop` and `lume delete` outside the lock, frees the slot and prints the worktree as reclaimed. Under the lock, `vm up` and `vm status` delete the clone and free the slot of a `starting` lease with a dead owner, of a `ready` lease whose clone is gone, and of an `app-qa-slot-*` clone without a slot, printing each. A slot whose owner is alive is never touched. Tests: an idle lease is reclaimed; an idle lease with a live busy pid is not reclaimed (exit 2); `vm status` during another worktree's starting `vm up` (fake clone held open) deletes nothing; a killed `vm up` (dead owner, `starting`) is cleaned by `vm status`; an orphan clone is deleted; `vm down` during a routed command exits 2; the image is never named in a `lume run`, `stop` or `delete` call. Verify: `node --test --test-name-pattern='^lease: (reclaim|busy|starting|crashed|orphan|down-busy|image)' team-config/agent/skills/app-qa-drivers/scripts/qa.test.mjs`
- [ ] 2.3 Teardown (spec "Teardown removes the clone and everything copied into it", design D4): `vm down` sets `closing` under the lock, kills the recorded forward pid, runs `lume stop` and `lume delete` on the clone and removes the slot directory; it exits 0 without a lease. ## 3. Staging and targets

- [ ] 3.1 Build and copy (spec "Staging builds on the host and copies the worktree, the artifacts and the credentials into the leased clone only", design D5): before taking a slot, `vm up` runs each target's `build.argv` without a shell in `build.cwd`, with `{port}` replaced by P. It then takes the slot, runs `lume clone`, then `lume run --detach --display none --vnc disabled` when the clone is not running, and waits for SSH. It streams the driver directory, and the credentials file over stdin with umask 077.
