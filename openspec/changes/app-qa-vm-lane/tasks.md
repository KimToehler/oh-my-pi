# Tasks

Paths are relative to the repository root, and `S` is `team-config/agent/skills/app-qa-drivers/scripts`. Apply starts after this branch has been rebased onto `main` with `feat/app-qa-computer-use-exception` merged (design D11).

Every driver task is test-first: its new tests are run and seen failing before the code they cover is written. The tests use the existing harness with fake tools on the test PATH and a private HOME (`S/qa.test.mjs:1-5`), plus these fakes:

- `lume`: logs its argument vectors and keeps a clone list in a state file.
- `ssh`: logs its argument vector, runs the joined remote command through `sh -c` (as sshd does) in a guest directory on the local disk, and can be told to exit 255.
- `launchctl`, `java`: test doubles for the desktop start.

Test names start with their area (`config:`, `lane:`, `lease:`, `stage:`, `target:`, `route:`), so each Verify selects its own.
