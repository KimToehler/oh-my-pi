# Tasks

Paths are relative to the repository root, and `S` is `team-config/agent/skills/app-qa-drivers/scripts`. Apply starts after this branch has been rebased onto `main` with `feat/app-qa-computer-use-exception` merged (design D11).

Every driver task is test-first: its new tests are run and seen failing before the code they cover is written. The tests run fake `lume` and `ssh` executables from the test PATH, in the existing pattern of fake tools (`S/qa.test.mjs:1-5`). These fakes log their argument vectors and serve a guest directory on the local disk, and the guest commands run there under the real `node`. Test names start with their area (`config:`, `lane:`, `lease:`, `stage:`, `route:`), so each Verify selects its own.

## 2. Leases and slots

- [ ] 2.1 Slot taking and lease lookup (spec "Leases take one of a fixed number of host-wide slots, one lease per worktree", design D4): Slots are `${TMPDIR}/app-qa/vm/slot-N`, taken with an atomic `mkdir`. `lease.json` holds the worktree's real path, the clone `app-qa-slot-N`, the targets, the forward pid and port, and `lastUsed`. `vm up` in a worktree holding a lease reuses that lease. With all slots busy or recently used, `vm up` exits 2 naming each holder's worktree and last use. Tests: Two worktrees each get their own slot and clone. The same worktree twice keeps one slot. A third worktree is refused with no `lume clone` in the fake log. Two `vm up` started together for one free slot: exactly one clones. Verify: `node --test --test-name-pattern='^lease: (slot|parallel|refuse|simultaneous)' team-config/agent/skills/app-qa-drivers/scripts/qa.test.mjs`
- [ ] 2.2 Reclaim and sweep (spec "Idle and orphaned VMs are reclaimed, busy ones never", design D4): Routed commands write and remove `busy/PID` and set `lastUsed` at start and end. With no free slot, `vm up` reclaims the lease idle longest beyond `idleMinutes` that has no live busy pid: `lume stop` and `lume delete` of its clone, its worktree printed as reclaimed. `vm up` and `vm status` delete `app-qa-slot-*` clones without a lease (from `lume ls --format json`) and remove leases whose clone is gone, printing each name. Tests: An idle lease is reclaimed. An idle lease with a live busy pid is not reclaimed (exit 2). An orphan clone is deleted by `vm status`. A live lease's clone is never deleted. The image is never named in a `lume run`, `stop` or `delete` call. Verify: `node --test --test-name-pattern='^lease: (reclaim|busy|orphan|image)' team-config/agent/skills/app-qa-drivers/scripts/qa.test.mjs`
- [ ] 2.3 Teardown (spec "Teardown removes the clone and everything copied into it", design D4): `vm down` kills the recorded forward pid, runs `lume stop` and `lume delete` on the clone and removes the slot directory. It exits 0 without a lease. Tests: After `vm down`, the fake `lume` lists no clone, the forward process is gone and `vm status` shows the slot free. `vm down` in another worktree leaves the lease alone. Verify: `node --test --test-name-pattern='^lease: down' team-config/agent/skills/app-qa-drivers/scripts/qa.test.mjs`
