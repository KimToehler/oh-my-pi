## Findings

### F1-lease-table-has-no-in-progress-state-or-mutex
- **Disposition**: adopted: design.md D4 adds the table lock, lease record written at slot take with owner pid and state (starting, ready, closing), sweep and reclaim rules respecting live owners, refresh and `vm down` refused while a routed command runs; spec requirements on leases and reclaim name the starting state, serialisation and crashed start; tasks.md 2.1-2.3 test each interleaving and the crashed start.

### F2-mtime-freshness-gate-refuses-states-a-rebuild-cannot-clear
- **Disposition**: adopted: the mtime comparison is removed; `vm.<target>.build` (argv, cwd, `{port}`) is configured and run by `vm up` before taking a slot (design.md D5 step 1, D8; spec staging requirement; proposal.md; gate.md residual replaced; tasks.md 1.1 and 3.1; F1 `stage-nc` uses a compile error).

### F3-routed-argument-cwd-and-fix-line-translation-is-undefined
- **Disposition**: adopted: design.md D7 holds the closed translation table (working directory, FLOW, refused `--config`/`--credentials`, private `--out` and default output folder, kept root), POSIX quoting with an `sh -c` fake ssh, and the `vm up TARGET` line on a non-zero exit; new spec requirement "Routed commands reach the guest driver with the caller's arguments and location"; tasks.md 4.2 and 4.3; F1 rows `args-shell`, `args-nc`, `out-noout`.

### F4-rerun-and-lease-health-semantics-are-undefined
- **Disposition**: adopted: design.md D5 makes `vm up` a reconcile (stopped clone run again, forward killed before restart, fresh simulator per `vm up`, desktop killed and started), D2 maps a stopped clone, dead forward and ssh exit 255 to exit 2 naming `vm up TARGET`; spec requirement "Every vm up leaves each staged target in one known state" and the routing requirement updated; tasks.md 3.2, 3.3, 4.1; F1 `target-rerun`, `route-nc`.

### F5-three-mechanisms-the-existing-code-makes-unnecessary
- **Disposition**: adopted: `APP_QA_VM_CONFIG` dropped (design.md D3, tasks.md 1.2 use the suite's private HOME), `git init` without a commit (D5 step 4), target start moved into the guest-side `scripts/vm/start-target.mjs` with fake `xcrun`, `launchctl` and `java` tests (D6, tasks.md 3.2, 5.3).
