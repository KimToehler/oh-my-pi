# Tasks

`E` is `.omp/team-config/evidence/gate/comment-commits/f1/`.

Replay rows. Each row applies the edited `team-config/agent/skills/review-work/SKILL.md` to one constructed case and records the decision it produces. Each row writes one evidence file under `E` naming the case, the instruction sentence that decides it (quoted verbatim from the file) and the decision, and one entry in `E/qa-matrix.json` (`qa` array) with `name`, `sentence`, `action`, `expected`, `observed`, `passed` and `artifact` (`path` relative to `E`, `sha256`). Decisions come from the fixed set `exempt`, `delta-review`, `after-merge`, `code-on-branch`, `no-summary`, `blocked`, `install-identical`. The checker in each Verify command requires exactly the named rows, `passed` true, `observed` equal to the row's fixed expected decision, the artifact hash, and the quoted sentence present (whitespace-normalised) in both the evidence file and the current instruction file.
