# Tasks

`E` is `.omp/team-config/evidence/gate/review-stop-rule/f1/`. The measurement data is `runs/gate-e2e-20261029/data.json` in the main checkout.

Replay rows. Each row applies one edited instruction file to one case and records the decision it produces. A row's case is a recorded blocker or commit from `data.json` and its cited `review.md` or gate records, read verbatim; when the cohort holds no such case, the row uses a constructed case and its evidence file says `constructed`. Each row writes one evidence file under `E` naming its source, the case as read, the instruction sentence that decides it (quoted verbatim from the edited file) and the resulting decision, and one entry in `E/qa-matrix.json` (`qa` array) with `name`, `file` (the edited file the sentence comes from), `sentence`, `action`, `expected`, `observed`, `passed` and `artifact` (`path` relative to `E`, `sha256`). Decisions come from the fixed set `ask-accept-recommended`, `ask-accept-withheld` (the ask offers fix, re-plan or stop but not accept or freeze for a named non-eligible blocker), `fix-blocking`, `exempt`, `delta-review`, `downgrade-recorded`, `residual-recorded`, `user-accept-recorded` (an explicit user acceptance recorded with the user's reason and the blocker's stated consequence) and `install-identical`. A row whose observed decision differs from its expected one fails. The Verify commands bind every row name to its expected decision, check the artifact hash, and check that the quoted sentence occurs in the named edited file and in the evidence.
