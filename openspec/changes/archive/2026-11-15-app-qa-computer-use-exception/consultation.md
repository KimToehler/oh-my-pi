### F2-global-rule-reaches-non-qa-sessions

- **Disposition**: adopted: design.md D18(b) and Risks; tasks.md 2.9 (condition six trimmed to `\bcomputer\.[A-Za-z]`, the D16 paragraph guarded to app QA or a repository with `.omp/app-qa.json`) and 2.8 (the new rule's guard); spec scenario "Search with ignore rules off outside app QA"; F1 row `noqa-session`; condition nine kept (visual QA drives UI too)

### F3-background-only-depends-on-an-unnamed-setting

- **Disposition**: adopted: design.md D18(c); tasks.md 1.8 (`computer.backgroundFallback: refuse` as a precondition, "ran in takeover" stops the session); spec scenario "Setting is not refuse" and the negative control; F1 sessions run with the setting in a config overlay, recorded in the evidence header, and a "ran in takeover" outcome fails `ce-voiceover`, `ce-vo-unfocused`, `ce-hostmenu` and `ce-dialog`

### F4-host-window-is-shared-across-repositories

- **Disposition**: adopted: design.md D18(d); spec requirement "Computer use reads one target window at a time" drops the host window as a target and adds scenario "Host menu only" (menu items and select only, effect confirmed by a second `menu.items` or the driver, no step while another process holds the flow lock); tasks.md 1.8; TalkBack dropped from the screen-reader surface in proposal.md, spec and skill text; row `ce-hostmenu` updated with a held-lock run

### F5-no-sanctioned-way-to-start-stop-or-steer-the-screen-reader
