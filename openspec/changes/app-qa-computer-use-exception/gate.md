# Gate

- **Mandatory class**: auth-secrets-pii
- **Depth**: risky (the mandatory class)
- **Risk tier**: product
- **Author's risk assessment**: The change relaxes a ban that sits next to the team's credential guardrail: it lets a session take window screenshots and accessibility reads of a host desktop on which dev accounts sign in to real identity-provider pages and password managers. A wrong boundary (an exception read as "any dialog", a missed password-manager overlay, a rule that does not load before a `computer` call) lands a screenshot or an element value holding a real dev password in a transcript that cannot be scrubbed; that consequence is why the class is auth-secrets-pii and not `none`, although the change handles no credential itself and edits only instruction text and one rule trigger. Product tier: the skill and rule govern every agent session that drives an app with real accounts.
- **Whole-diff review**: not needed (whole-diff surface reviewed in F2)
- **Accepted residual risks**: A password-manager or save-password dialog can appear between the pre-capture window check and a screenshot; the window-only, zoomed capture and the rule's pause reduce the area but cannot exclude it. The rule and skill are guidance, not enforcement, as for the driver change (`team-config/README.md:343`): a session can ignore them. Whether a `computer` call matches the new rule condition depends on the call's text; a helper spelled in a way the regex misses does not load the rule until a later matching call. The measured token costs are one pass on one app (2026-11-12) and are cited as the reason for the rules, not as limits.
- **Out of scope for blocking**: the `computer` prelude itself and its settings or defaults (`computer.enabled` stays `false` in code); `qa.mjs` and its tests; onara's and weaver's repository QA skills and any app-specific VoiceOver procedure; the DeviceHub input skill; Android TalkBack tooling beyond naming it as a surface; the unchanged sections of `ui-automation-credentials` and `team-config/agent/AGENTS.md:20`. Findings there become follow-ups.
