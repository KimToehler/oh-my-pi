# Gate

- **Mandatory class**: concurrency-state
- **Risk tier**: product
- **Author's risk assessment**: The change alters the plan review that every repository deploying team-config must pass before `/opsx-apply` may edit source, so the tier is product. The worst realistic failure is fail-open: a round recorded as OKAY although a lens rejected or never ran, letting a weaker-reviewed plan reach implementation; the new OKAY-with-blockers guard closes the case where the blockers were recorded, the rest stays prompt-level as today. A validator defect could also reject valid records (fail-closed): an open change mid-implementation would then need a re-review, which is recoverable but costs a review round and can surface new blockers on a plan already being implemented. Class concurrency-state: the change redefines the predicate that moves a change from review-blocked to apply-ready and the record format that predicate reads.
- **Whole-diff review**: not needed (two modules, the `omp-gated` review instruction with its template and the OpenSpec validator, sharing one record format)
- **Accepted residual risks**: The validator cannot witness that three lens tasks were dispatched, that their briefs were verbatim, or that the verdict was composed from all three results; an agent that skips lenses or fabricates a record passes, as it can today. A one-id record written after this change is accepted, so a project whose schema copy was not reinstalled keeps reviewing with one reviewer. The retry and incomplete-round branch (D4) gets no deterministic live witness; it is prompt-level guidance exercised only when a lens fails. Whether lens rounds reduce the number of rounds to OKAY is not measured by this change.
- **Out of scope for blocking**: the `plan-reviewer` agent prompt and model role; fix-delta reviews (`verdict.json`) and plan-mode plan reviews; verifying or deduplicating blockers before they are fixed; stalled-subagent detection in the `task` tool; projects (onara, weaver) and agent directories that have not redeployed.
